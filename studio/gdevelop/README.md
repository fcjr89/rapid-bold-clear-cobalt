# GDevelop masters (high-res concepts)

Source: original GDevelop project **13 Bloodlines of the Illuminati**.

- `masters/` — full-resolution concept JPGs (canonical visual source when better than web exports)
- `web-exports/` — high-quality web JPEGs derived from masters (better than older tiny `public/game/art` compressions)
- `concepts-for-gen/` — 512px thumbs for image-gen reference
- `gdevelop-pixel-assets.zip` — original GDevelop pixel sprites/UI
- Project JSON preserved alongside

**Policy:** Prefer these hi-res masters as concepts. Gameplay can keep `public/game/art` until upgraded from `web-exports/`.
