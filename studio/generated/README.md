# Studio generated art (optional)

These are Grok-generated pieces the team liked. They are **not** the canonical in-game assets.

- **Canonical gameplay art:** `public/game/` (your originals)
- **Optional studio set:** this folder
- **Platform optimized exports:** `studio/optimized/` (Steam / mobile / console)

To try a generated portrait in-game without losing originals, copy over a file from here into `public/game/art/` on a feature branch.
