# Studio generated art (optional)

These are Grok-generated pieces the team liked for **Culture War / Baki The Hammer**. They are **not** the canonical in-game assets.

- **Canonical gameplay art:** `public/game/` (and `public/game/art/`) — originals remain what BootScene and the gallery load
- **Optional studio set:** this folder (`art/*.jpg` mirrors gallery filenames; also `title.jpg`, `tiles.png`, `baki-portrait.jpg`, `bg-thrones.jpg`)
- **Platform optimized exports:** `studio/optimized/` (Steam → mobile → console), derived from **user originals**, not from these gens

To try a generated portrait in-game without losing originals, copy a file from here into `public/game/art/` (or the matching root path) on a feature branch. See `docs/ART_PIPELINE.md`.
