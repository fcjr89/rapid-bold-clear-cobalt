# Platform optimized art

Order: **Steam → iOS → Android → consoles**.

| Folder | Role |
|--------|------|
| `steam/` | Store icon 512, library hero, capsule sizes, web-friendly copies |
| `mobile/` | `@2x` / `@3x` WebP/JPEG/PNG for key UI & portraits |
| `console/` | Power-of-two padded textures + `CONSOLE_ART.md` |

Canonical gameplay art stays in `public/game/`. See `docs/ART_PIPELINE.md`.
